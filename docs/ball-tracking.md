# 足球检测与轨迹接入

## 已接入的内容

足球与球员分别保存，不将足球混进球员跟踪编号、球队分类或战术指标。网页在同一帧显示：

- 原始视频上的黄色检测框、圆圈和最近 2 秒的图像轨迹。
- 当前检测置信度、图像坐标、关联轨迹段及缺失状态。
- 球场图上的黑白足球标记及虚线轨迹，明确标注为地面近似投影。
- 足球显示开关；切换球队、站位、球员轨迹或热区不会替换足球观测。

没有插值补漏检，没有把预测位置保存为当前检测。缺失和重新捕获会分开轨迹段；帧编号或轨迹段不连续时断线。尚未识别球权、传球、射门、进球、三维高度或真实落地点，智能体查询工具暂时也没有接入足球记录。

## 生成方式

为已有球员分析补充足球，不重新识别球员：

```bash
python3 -m examples.soccer.track_ball \
  --analysis examples/soccer/data/validation-0bfacc-refined/analysis.json \
  --device auto --save-video
```

默认输出到对应分析目录的 `ball/`，包含 `ball.json`、`ball.csv` 和可选的 `ball-review.mp4`。目录非空时拒绝覆盖，可用 `--output-dir` 指定新目录。`--max-frames` 用于短样本试跑；少于原分析帧数的结果标为 incomplete，网页不会将其当作完整结果加载。视频目前从分析元数据指定的位置读取，移动到其他电脑时需保证该路径对应正确视频。

新的 `examples.soccer.analyze` 流程在球员分析完成后默认追加足球检测；`--skip-ball` 可只保留球员分析。足球检测失败不会删除已保存的球员结果，可修复后单独执行上述命令。原上游独立 `BALL_DETECTION` 示例保留。

工作台启动时自动读取同目录的 `ball/ball.json`。生成后重启 `python3 -m examples.soccer.web` 即可显示。无文件、不完整、文件损坏或校验不一致时，网页说明原因，球员数据仍可使用，不提供模拟足球。

## 算法与记录口径

使用本机已有 `football-ball-detection.pt`，第 0 类为 ball。图像按 640×640 切片、128 像素重叠处理，小球避免整帧缩小造成细节损失；切片候选转回全图后做非极大值抑制。初始置信度阈值 0.25，NMS IoU 阈值 0.1，参数不是经独立标注集验证的最佳值。

采用图像距离门控与短期运动参考选择当前实际候选，最大关联间隔 5 帧，距离门控为图像对角线的 0.06 倍乘间隔帧数。运动参考仅用于选择候选，不对没有检测的帧输出位置。长间隔或图像直方图提示镜头变化后重新捕获；镜头检测是启发式方法，尚未在切镜数据集上评价。

每条记录包含：帧编号、时间、是否检出、检测框中心、检测框、模型置信度、轨迹段、关联状态、候选数、球场投影及投影有效性。置信度来自模型，不等于经校准的正确概率。

导出文件保存视频及球员分析文件的 SHA256。网页核验两项摘要、时间戳、帧编号、完整性及数值，防止混用视频或球场映射。修改分析文件或重新映射后，需要为新结果重新生成足球文件，不能沿用旧投影。

## 为什么不能把球场点当成真实球位置

球员使用脚点映射，足球使用图像中心。单目视频中的空中球不在球场平面上，直接使用地面单应性会产生偏差。目前无法判断球是否贴地，所有球记录的 `grounded_verified` 均为 false；`projection_valid` 只表示当前几何映射有效且投影在边界内，不表示足球真实场地位置准确。

球场映射无效时，仍可显示原始画面中的检测框和图像轨迹，但不显示该帧的球场足球点。投影无效、漏检或关联失败时不保留历史足球点冒充当前点。轨迹同样不支持真实米制距离或速度估计。

## 2026-11-18 实测

样本为现有第二段 `0bfacc_0.mp4` 前 10 秒，1920×1080、25 fps，共 250 帧；使用本机 MPS 和现有权重，球员坐标与统计未重算。

- 227 帧产生足球检测，检出比例 90.8%；18 帧没有通过筛选的候选，5 帧候选未通过关联门控。该比例不是准确率、召回率或跟踪准确率。
- 159 帧产生边界内地面近似投影；68 帧虽检出球但该帧映射无效，其余 23 帧没有可信足球观测。
- 8 个重新捕获记录，加首次初始化，共 9 个轨迹段，缺口保持断开。
- 抽查第 0、66、100、125、160、180、220、249 帧局部图，标记位于可见足球附近。尚未逐帧人工标注，不能据此声称全片无误检或漏检。
- 第 125 帧示例：图像中心约 `(1065.7, 767.4)` px，置信度 58.7%；地面投影约 `(50.1%, 92.4%)`，仍未验证是否贴地。
- 当前样本未出现被直方图阈值判为切镜的帧，不能据此证明真实镜头切换场景稳定。

47 项自动测试通过，覆盖已有功能、足球候选关联、漏检、断段、镜头重置、切片边缘、重复框抑制、视频与映射匹配、异常投影等。15 项浏览器检查通过，覆盖坐标逐值一致、置信度、图像检测与投影分离、漏检不补点、轨迹断点、显示开关及窄屏布局。本次没有额外调用付费模型。

本地结果与抽查图位于忽略的分析目录 `examples/soccer/data/validation-0bfacc-refined/ball/`；网页截图与检查记录位于 `outputs/ball-web-check/`。这些视频、模型及本地结果不提交 Git。
