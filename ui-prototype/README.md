# 足球战术分析 UI 交互原型

当前仅用于确认界面与操作流程，尚未接入真实指标、坐标或 DeepSeek 服务，也没有部署到服务器。采用独立 HTML、CSS 和 JavaScript，无需安装前端依赖或启动后端；这不是对最终前端框架的选型。

## 打开方式

直接在桌面浏览器打开本目录 `index.html`。默认播放本仓库已有的 `examples/soccer/data/0bfacc_0.mp4` 前 10 秒；如果文件不在本机，可点击“选择本地视频”，仅在浏览器内播放，不上传。选择其他视频不会计算对应站位或统计。

字体统一指定微软雅黑。本机从已有 Microsoft Word 字体准备了仅供本地预览的字体副本，位于 Git 忽略的 `local-fonts/`，不提交、不分发。其他设备若没有微软雅黑或该本地副本，会使用系统无衬线字体回退。

## 已实现的交互

- 视频播放、暂停、倍速和全屏；时间轴拖动到指定时间。
- 前 5 秒、后 5 秒和完整片段的选择；时间范围同步到问答上下文和曲线高亮。
- 切换球队，更新演示指标及对应的轨迹、热区。
- 包含完整禁区、球门区、球门、中圈和禁区弧的二维球场；点击或用键盘选中模拟球员，查看相对坐标。
- 问题输入、快捷提问及固定演示回答；每条回答保存当时选择的球队与片段供证据弹窗查看。
- 战术知识目录、卡片摘要和官方来源链接，以及数据说明弹窗。
- 窄屏响应式排列、键盘焦点、原生弹窗关闭与减少动态效果设置。

## 数据边界

原型的指标、曲线、站位、轨迹、热区及回答均为演示。部分数值沿用历史测试结果以呈现真实的数据量级，但未与当前播放时刻绑定，不应视为本视频的完整分析结果。热区只是模拟点扩散，不是累计活动密度。球队编号与蓝橙标记均用于演示，不代表实际球衣或俱乐部。

问答不读取密钥、不连接模型或服务器。知识卡片摘要用于预览，正式页面应由后端读取仓库知识库，避免维护两份正文。点击外部来源链接会由浏览器访问对应站点。

## 视觉方向

主要参考用户选定的 [Atish Chakma：Football Match Analytics Dashboard – Live Stats & Chat](https://dribbble.com/shots/26517374-Football-Match-Analytics-Dashboard-Live-Stats-Chat)，保留浅色卡片、左侧聊天、中央视频和下方统计的结构，并按已确认需求加入右侧球场图。属于面向本项目内容的参考复刻，未验证为原图像素级一致，也没有使用参考设计的前端源码。

- 白色卡片与浅灰工作区，珊瑚红作为交互强调色。
- 左侧问答，中央回放与指标，右侧站位和质量提示。
- 统计百分比与数据可用率保持可见；知识和数据证据可进一步展开。
