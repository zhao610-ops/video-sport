# 本机真实分析工作台

本目录将已确认的界面连接到已有足球视频分析结果。原静态原型保留在 `ui-prototype/`，本版本不使用模拟坐标、预设指标或固定聊天回答。

## 启动

在仓库根目录执行：

```bash
python3 -m examples.soccer.web
```

浏览器打开 `http://127.0.0.1:8765`。停止服务时在启动终端按 Ctrl+C。默认读取 `examples/soccer/data/validation-0bfacc-refined/analysis.json` 与其原始视频；目前只有视频前 10 秒、250 帧已有分析结果，视频其余部分没有自动补算。

Windows 可以使用 `.\.venv\Scripts\python.exe -m examples.soccer.web`。仅查看已有结果不加载检测模型或 GPU，也不需要安装新的前端依赖；本机服务使用 Python 标准库。尚未做 Windows 实机端到端验证。

指定其他已分析结果或移动后的视频：

```bash
python3 -m examples.soccer.web --analysis /path/to/analysis.json --video /path/to/matching-video.mp4 --port 8765
```

视频必须与坐标文件对应，尚未实现视频哈希核验。当前没有网页上传新视频并启动识别任务的入口。

## 数据与统计

- 服务端从已保存坐标调用原有 `calculate_tactics` 重新计算指标，不重新识别视频；本次与已保存的 500 条球队逐帧指标逐项一致。
- 视频时间按 `frame_index / fps` 对齐，查询当前播放时间所属的已保存帧；可逐帧查看。
- 无效映射不显示历史站位；重复跟踪编号、未知球队、异常坐标不进入显示点集。
- 统计排除守门员，球场图以空心点单独保留有效守门员数据。
- 指标对可用帧等权平均，缺失不补零；图表缺失处断开，不平滑。
- 球队中心、宽度、纵向跨度使用百分比；球队编号不代表主客队，坐标方向不代表进攻方向。
- 轨迹使用所选队伍指标可用帧中的有效非守门员，并在帧缺失处断开；热区按相同口径累计所选片段的位置观测密度，按网格计数显示，不代表真实的全场空间控制。
- 球场标线直接复用分析时的模板生成，包含完整禁区等标线。参考场地尺寸不会升级为历史比赛实测值。

## 真实问答与证据

在仓库根目录 `.env` 配置 `DEEPSEEK_API_KEY`，只在服务端读取，不通过浏览器输入或下发。当前按用户选择使用 `deepseek-flash`，关闭思考模式。修改密钥后重启服务。

点击提问后，后端将当前球队和时间段作为上下文，调用原有统计和知识工具；知识正文直接读取 `knowledge/football_tactics.json`，没有另行维护界面版知识摘要。每次问答可能计费，最多 6 次模型请求、12 次工具调用，服务一次只接受一个正在进行的模型问题，不自动重试付费失败请求。

回答的“查看本次真实工具证据”显示实际参数、返回值、检索卡片和来源。成功结果保存在 `outputs/web-agent/<随机编号>/trace.json` 和 `answer.md`；达到轮次限制时保存脱敏工具记录与引用校验诊断，不保存或展示伪造答案。网络、余额或证据校验失败时页面明确报错，不切换到演示回答。

只有问题、数据口径、相关统计和检索知识发送给 DeepSeek，原视频与本机文件绝对路径不下发给模型。回答本身仍需人工核查，引用检查不等于逐句事实验证。

## 本机使用边界

服务仅监听 `127.0.0.1`，检查 Host 与 POST Origin；只提供固定网页资源、当前视频和指定数据的接口，不开放任意文件读取。视频支持 HTTP Range 以便拖动播放。没有将本服务作为公网产品部署，也没有配置用户登录或云端任务队列。

## 2026-11-18 验证

- 真实网页的 17 项首轮浏览器检查通过，包括 250 帧加载、同帧坐标逐值一致、真实汇总、无效帧清空、轨迹、热区、曲线断点、统一知识来源及窄屏布局。
- 全项目 37 项自动测试通过，新增 API 测试使用临时数据和模拟模型，不产生外部 API 费用。
- 首次网页问答达到 6 轮证据校验上限而失败；改进校验反馈并补充失败诊断后，针对同一问题进行了真实复测。
- 复测问题为球队 0 在 `[5,10)` 秒的宽度、纵向跨度以及能否确定高位逼抢，返回约 65.8%、27.9%、94.4% 可用率，并引用实际统计与 FIFA 知识说明证据不足；所有成功工具结果与本地复算一致。
- 测试截图与问答结果保存在本地忽略目录 `outputs/web-check/`，没有上传视频、密钥或本地回答文件。

这证明了当前片段上的读取、联动和真实工具问答流程；不代表定位准确率、战术分类能力或多视频泛化已经验收。
